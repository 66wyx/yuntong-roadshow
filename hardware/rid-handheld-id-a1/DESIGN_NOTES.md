**云瞳 RID · ID-A1 外观设计说明**

本轮按用户要求将外观优先级置于器件排布之前：CNC 铝合金中框、3D 打印前盖与后盖。使用 Blender MCP 在 Blender 5.2 中建立独立场景，模型包含分别命名的实体、材质、三种屏幕视觉稿、多角度相机和可展开的结构分组。A0 的硬件占位保留作历史输入，不再决定本轮正面比例。

机身外观目标为 **82 × 86 × 20 mm**，不含突出按键。参考图的机身宽高约为 0.95；上一版 82 × 76 mm 过宽，本版恢复为略偏竖的方形。尺寸是 ID 目标，尚未重新验证屏幕、PCB、电池和天线装配。

| 参考中可辨识的外观元素 | 本版处理 |
|---|---|
| 圆润的方形机身与小圆角 | 82 × 86，平面圆角约 R6；前后盖边缘有独立软化处理 |
| 左侧高占比黑色长屏、窄外边 | 黑色盖板约 56.4 × 80.6，圆角 R3；周围保留细密的黑色装配缝 |
| 右侧上下两道横向分缝 | 保留在上部标志区和底部字标区边界；建成浅凹槽，未画成浮在表面的线 |
| 顶部黑橙棋盘状标记 | 建立七个独立小方块；下排第一格保留橙色 |
| 长形上下键 | 一体胶囊外轮廓、两个独立键帽、中间直分缝、深灰色细箭头 |
| 橙色圆形确认键 | 细倒角、深色底座、内外同心细圈、80 道边缘刻纹与细勾形标记 |
| 底部字标的位置与留白 | RID 产品版使用“云瞳 / AIRSPACE”；参考图版本保留“マスター”字样用于对照 |
| 灰色细颗粒表面 | 前后盖采用微颗粒哑光聚合物效果，中框采用有金属反射的细喷砂灰色效果 |
| 参考图像素屏内容 | 单独提供天气、点阵图标、01:00、日期和启动提示的外观对照版本；不是新增产品功能 |

此前已确定的功能继续体现：前面保留低矮的 M 键，位于确认键下方；顶部设受保护的电源键；Type-C 位于底部中框，并将金属口、绝缘舌片和触点分别建模，入口内凹。M 键是相对最初参考图的功能补充，视觉上缩小处理，不抢确认键的层级。

材料与表面目标：

| 部件 | 工艺方向 | 外观目标 |
|---|---|---|
| 中框 | 6061 铝合金 CNC，细喷砂与灰色阳极氧化作为候选 | 温灰金属反射；上下边缘窄倒角捕捉亮线 |
| 前后盖 | 3D 打印聚合物，优先验证精细打印及后处理 | 灰色细哑光；样件需验证纹理、涂层和尺寸稳定性 |
| 上下键 | 独立打印键帽、浅灰表面 | 指腹可分辨形状，箭头细而清楚 |
| 确认键 | 独立打印键帽、暖橙表面 | 作为唯一的大面积颜色重点，保留细圈与边缘刻纹 |
| 屏幕盖板 | 黑色盖板视觉模型，最终材料待显示选型 | 高占比、窄缝、低反光控制；本轮不是玻璃加工图 |

中框已按开口环形部件建模，上下盖分离，带接口切口；尚未包含完整刀具可达性、装夹、公差链、螺纹、热处理和表面处理补偿。后盖的内凹螺钉、低调防滑槽和背面字标是本轮提出的设计，原图没有给出背面，不能称为对原图背面的复刻。

金属中框使 A0 的侧壁天线位置失效。当前在前盖上部和后盖预留聚合物窗口区域，实际天线馈点、地平面、与金属的距离和整机方向图仍需重做。该安排是设计推论，不是已经验证的射频方案；[Espressif 的模组说明](https://developer.espressif.com/blog/2025/03/espressif-part-numbers-explained/)指出金属外壳会影响天线布置，[u-blox GNSS 天线应用说明](https://content.u-blox.com/sites/default/files/products/documents/GNSS-Antennas_AppNote_%28UBX-15030289%29.pdf)讨论了天线、地平面和外壳环境对性能的影响。

本轮黑色盖板与 UI 区域先服务于外观，**原来的 2.4 英寸 LCD 不再视为匹配这一正面的已定料号**。下一步应按这组窗口与外边界重新比较显示模组尺寸；内部布局随后适配，而不是再次缩小界面来迁就 A0 的占位。

模型、渲染和尺寸均属于外观评审资料。屏幕内容明确为演示；没有新增实际 RID 接收、测高或充电能力的验证结论。
