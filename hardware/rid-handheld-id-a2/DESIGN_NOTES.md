# ID-A2 设计输入与复核记录

日期：2026-10-30。以本轮用户选择的 AM200Q460460FLS1、铝壳包围正面和三次贝塞尔四角为准。A1 的 82 × 86 × 20 mm 三段包夹结构退出当前外观。

## 材质与结构

侧壁与正面金属围边建为一个 CNC 铝壳实体；手掌握住侧边、手指经过四角和正面周缘时接触铝件。前面板为内嵌打印件，装在金属唇边以内，下沉 0.35 mm；背部打印盖也装在铝壁内部。装配缝藏在内周边，不再沿侧壁形成上下两条分层带。

前面板设计有内侧窄定位翻边。为讨论从后部装入的路径，翻边包络设为 59.8 × 49.8 mm，铝壳内腔设为 60.4 × 50.4 mm。尚未设计螺柱、扣位、装配顺序细节及工艺公差。后盖四枚内沉螺钉和握持细槽为 ID 提案。

## 四角的三次贝塞尔定义

每个 90° 角用两段三次贝塞尔组成。以进入上方直边处为原点，X 朝右、Y 朝下，按角部长度 L 归一化：

```
第一段：P0=(0,0), P1=(0.28L,0), P2=(0.64L,0), P3=(0.82L,0.18L)
第二段：Q0=P3, Q1=(L,0.36L), Q2=(L,0.72L), Q3=(L,L)
```

首尾相邻的三个控制点分别共线，曲率在直边连接处为零；两段中间的位置、一阶导数和二阶导数相等。其余三角通过镜像生成。这样可实现与直线的 G2 连接及两段曲线间 C2 连接。外框与内框采用相同构造，角部金属宽度略有变化，并非严格等距偏移。

参数以用户要求的 iPhone 直板机视觉为参考自主构造，没有声称测绘、取得或复用苹果的官方外形曲线。0.25 mm 的边缘柔化是截面处理，与平面内的贝塞尔角部曲线分开设置。

Blender 保留 `RID_A2_Cubic_corner_control_path` 精确控制柄；实体轮廓按每段 32 步采样。主要实体的封闭性和曲线导数误差记录在 `geometry-review.json`。SVG 保留精确 cubic path，方便后续 CAD 曲线重建。

| 操作 | 行为提案 |
|---|---|
| ↑ / ↓ 短按 | 切换目标；菜单内上下移动 |

| 电源短按 | 熄屏 / 唤醒，继续接收的行为待功耗评估 |

屏幕适配采用大图形、两项主读数、底部目标与数据年龄。平放展示雷达视图，竖持展示高度示意；自动切换需滞回和停留时间，避免手抖反复切换。当前两张图均标记 DEMO，显示 168 m、相对高度约 +62 m、右前方 17° 是示例数据。

高度图只能使用明确高度基准的广播值与本机定位信息；高度基准未知、位置无效、航向未校准或目标过期时，应显示未知/失效状态，不能生成看似准确的空间位置。此条是 UI 行为约束，本版尚未实现传感器与协议软件。
