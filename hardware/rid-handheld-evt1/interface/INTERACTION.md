**240 × 320 界面与实体按键基线**

对应用户选定的左屏、右侧正面实体键外观。`radar-demo.svg` 和 `height-demo.svg` 是目标像素尺寸的视觉稿，所有飞机和数值均为演示；尚未编写 LCD/LVGL 显示驱动。

| 输入 | 总览 / 跟随 | 菜单 / 详情 |
|---|---|---|
| ▲ / ▼ 短按 | 上/下一个目标，目标排序在一次选择期间保持稳定 | 移动选项 |
| 橙色 ✓ 短按 | 选定或取消目标跟随 | 确认 |
| 橙色 ✓ 长按 1 s | 打开当前目标详情 | 无重复动作 |
| M 短按 | 自动 → 雷达 → 高度 → 自动 | 返回上一层 |
| M 长按 1 s | 打开设置；设置含范围、亮度、校准和诊断 | 返回总览 |
| 顶部电源短按 | 息屏 / 唤醒，接收与记录继续 | 同左 |
| 顶部电源长按 2 s | 开机；开机时显示关机确认，✓ 执行、M 取消 | 同左 |
| 顶部电源按住约 8 s | 独立硬件强制恢复路径，具体时序待电源电路确定 | 同左 |

消抖初值 30 ms；长按后抬起不再触发短按。菜单可在按住 ▲/▼ 500 ms 后每 160 ms 重复；目标切换不重复，防止跳过目标。进入菜单时锁定视图，不因持握切页。

自动视图：相对水平倾角 <25° 或 >60°，连续稳定 600 ms，分别进入俯视或高度；中间区域保留上一视图，明显移动时暂停切换。手动固定始终优先。切换不重置选定目标、范围和刷新时间。

俯视以本机为中心，外圈显示实际距离档位，目标越界时贴边并显示距离。箭头所示方向由校准后的真北航向计算；罗盘异常自动切北向上并显示原因。近似重合位置不画随机方向箭头。

竖持使用线框地面、投影点及高度柱；相对高度来自相同基准的双方位置高度。若纵轴放大，必须常驻标明倍率。没有可靠高度时显示“— / 高度未知”，保留水平位置。不是视觉测高或主动雷达。

状态栏显示 GNSS / 方向可靠性、接收状态和电池；下栏显示选定目标、水平距离、相对高度、位置年龄。身份包刷新不能让过期位置重新变成新鲜；本机或目标位置超过 3 s 暂停位置几何，详情仍可查看最后坐标与接收时间。

失效呈现：GNSS 未定位→列表与原始坐标；磁场异常→北向上；双方高度基准不一致→高度未知；已选目标陈旧→保留灰色身份但不显示当前方位；电量计通信失败→“—%”；充电状态由充电芯片解释，不用 SOC=100% 代替充满。录像/回放/场景演示全页保留“演示”标记。
